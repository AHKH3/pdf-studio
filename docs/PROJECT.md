# نطاق المشروع — PDF Studio

> المرجع الملزم لقرار «داخل/خارج النطاق» قبل أي ميزة أو تغيير كبير (دستور مجلد الشغل).
> آخر تحديث: 2026-09-16 — الإصدار 1.0.20، عشر أدوات.

## التعريف

تطبيق سطح مكتب (Electron، ويندوز فقط) عربي RTL يقدّم عمليات PDF اليومية **محليًا 100%**: بلا رفع، بلا حساب، بلا اشتراك، بلا حدود مصطنعة. المستخدم: أفراد عرب (طلاب/موظفون) ينجزون عملية واحدة على جهازهم الشخصي في أقل من دقيقة.

## داخل النطاق (يُنفَّذ مباشرة)

1. **الأدوات العشر المعلنة**: صور ← PDF (مسح + تجميع)، دمج، ترتيب، تقسيم، ضغط، ترقيم، PDF ← صور، تعديل PDF، قص، صور أصلية — بما فيها تحسين نفس الأداة (دقة الكشف، إعدادات الصفحة، إصلاحات UX).
2. **الصدفة**: التابات وعزل حالتها، الرئيسية والملفات الأخيرة، التثبيت/الإخفاء، الثيمات، الاختصارات، إمكانية الوصول (لوحة مفاتيح كاملة، تباين AA).
3. **قناة النشر**: مثبّت ويندوز NSIS فقط + تحديثات صامتة + صفحة الهبوط على GitHub Pages + أتمتة Release.
4. **التوثيق والمزامنة**: أي تغيير في `docs/*.md` أو `PRODUCT.md`/`DESIGN.md` يُزامَن إلى Linear (Documents/Issues) حسب قرار 2026-08-26.

## خارج النطاق (يتطلب شرح التكلفة + تأكيد صريح + تسجيل في DECISIONS.md)

1. أدوات جديدة كليًا أو إعادة المحذوفات (توقيع/حماية/علامة/OCR) — حُذفت بقرار 2026-09-06.
2. منصات جديدة (Portable/Linux/macOS) أو التقاط كاميرا حي — مرفوضة بقرارات 2026-08-26 (النشر NSIS فقط، المسح من ملفات موجودة).
3. أي خدمة سحابية أو تتبّع أو حسابات — تخالف المبدأ الأول في PRODUCT.md.
4. تعديل القرارات المسجلة أو تعريف النطاق أو الدستور دون إذن صريح.

## مجالات محظورة/مجمّدة

- `electron/main.cjs` وضع الأمان (`contextIsolation: true`، `sandbox: true`، `nodeIntegration: false`) — لا يُرخَّى أبدًا.
- خطوط الواجهة: Amiri + Noto Naskh Arabic + Playfair Display فقط (ممنوع Cairo/Inter).
- `assets/vendor/*.js` غير متتبَّعة (git-ignored) — تُبنى عبر `npm run vendor`، لا تُحرَّر يدويًا.

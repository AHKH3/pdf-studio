## 2026-09-07 — عزل كامل لحالة كل تاب (المرحلة 2)

- **الطلب:** نفس الأداة على نفس الملف في تابين كانتا تتشاركان التعديلات (singleton واحد) — «غير مقبول إطلاقًا». المطلوب: كل تاب نسخة مستقلة تمامًا.
- **القرار:**
  1. خطافان جديدان في كل أداة: `captureState()` (لقطة: مراجع الملفات + `saved` + قيم المدخلات، أو null) و`restoreState(state)` (استبدال كامل، وnull = تفريغ **لطيف بلا revoke/dispose/destroy** لأن اللقطات الأخرى تشارك المراجع). مساعدان في `shared.js`: `readInputValues`/`writeInputValues`.
  2. كل تاب تحمل `stores` (أداة → {state, name})؛ الالتقاط صراحةً قبل تبديل `activeKey` + خطاف `onRouteLeaving(leavingId, targetId)` يلتقط ويتبنّى الوجهة **ذريًا** (يمنع فساد التداخل الآجل)، ويجهّز الأداة للتاب الجديدة (reset + إعدادات افتراضية ملتقطة عند التركيب) قبل تسليم ملفات الـ hub.
  3. `route(..., { skipDeliver })` يتخطى تسليم الـ hub للتاب العائدة لعمل محفوظ حتى لا يتلوث.
  4. `settleNavigation` بعدّاد `navEpoch()` يُلغي النوايا المتقادمة عند أي تنقّل أحدث؛ وعند التعذّر التاب تعتمد الواقع الحالي وتمتلكه (لا حذف صامت).
  5. `dirty` لكل تاب (مجمّد عند آخر نشاط)؛ الإغلاق يحذّر منه، وإغلاق التطبيق يسأل عن أي تاب dirty. الأدوات بلا `isDirty` (المسح، القص) تُحذّر عند وجود عمل مفتوح.
  6. `confirmLeave` يُتجاوز بين التابات فقط (`skipConfirm`)؛ ضغطات الـ hub تحافظ على السلوك القديم.
- **قيود معلنة:** بقايا blob-URLs للمصغرات تُحتفظ بها (كيلوبايتات، لا نمو مع التنقل)؛ إعدادات تُقرأ عند التشغيل فقط تُترك (أداة التحرير: نوع الأداة/الألوان)؛ ملفات hub الجديدة لا تُحقن في تاب تحمل عملًا (استخدم زر الإضافة داخل الأداة، أو تاب جديدة).
- **التحقق:** 18 فحص E2E داخل Electron كلها خضراء (تابا دمج بنفس الملفين بترتيب/حذف مستقل + إعدادات تقسيم مستقلة + تحذير dirty).
- **التأثير:** `tabs.js`، `router.js`، `main.js` (تمرير الخطافات)، `shared.js`، والأدوات العشر الباقية (الصور حُذفت من المشروع بالتوازي).
- **بأمر:** المستخدم (مالك المشروع) صراحة («كمل» بعد عرض المشكلة).

## 2026-08-26 — تحديث NSIS صامت بالكامل (one-click per-user) — AHK-43

- **الطلب:** التحديث على ويندوز يظهر معالج Next/Next وسؤال مستخدم/Global؛ المطلوب صامت بالكامل ويعيد فتح التطبيق بلا نقرات. AHK-31 وُسِم Done خطأً.
- **القرار:**
  1. `nsis.oneClick: true` + `allowToChangeInstallationDirectory: false` + `perMachine: false` + `allowElevation: false` — مسار per-user one-click بلا معالج وبلا صفحة وضع التثبيت.
  2. كل مسارات التثبيت تستدعي `quitAndInstall(true, true)` (`/S` + `--force-run`): زر إعادة التشغيل، الإغلاق مع تحديث جاهز، و`--background-update`.
  3. تعطيل `autoInstallOnAppQuit` لأن معالج electron-updater الداخلي يستخدم `install(true, false)` فيفوت إعادة التشغيل؛ نستبدله بـ `before-quit` / إغلاق النافذة عبر نفس المساعد.
  4. سياسة المالك: ويندوز NSIS فقط — لا إعادة Portable/Linux.
- **التأثير:** `package.json` (`build.nsis`)، `electron/main.cjs`، `scripts/test-publish.mjs`، هذا الملف.
- **بأمر:** المستخدم (مالك المشروع) عبر AHK-43؛ تصحيح لحالة AHK-31.

## 2026-08-25 — إغلاق حتمي + تحديث صامت/خلفي + تسريع إقلاع (v1.2)

- **الطلب:** الإغلاق لا يُحبس أبدًا (beforeunload كان يعلّق النافذة)، زر التحديث يعيد التشغيل بصمت، تحديث خلفي والتطبيق مغلق، وإقلاع أسرع إلى الهيرو.
- **القرار:**
  1. حذف `beforeunload`. العملية الرئيسية تسأل `__pdfStudioHasUnsavedWork()` ثم حوار أصلي إن لزم، وبعدها `forceClose` و`app.exit(0)` خلال 5 ثوانٍ كحارس.
  2. زر «إعادة التشغيل» يستدعي `quitAndInstall(true, true)` مع الإبقاء على `autoInstallOnAppQuit`.
  3. `--background-update` بلا نوافذ. إن كان التطبيق مفتوحًا، `second-instance` يتجاهل التركيز ويكتفي بفحص تحديث. مثبّت NSIS (`build/installer.nsh`) يسجّل مهمتي Task Scheduler: كل 6 ساعات + عند Logon.
  4. تسريع: إزالة heic2any (≈1.3MB) من `<head>` (يُحمَّل عند الحاجة)، `addTools` تدريجي بعد الهيرو، وبدء سيرفر الحلقة المحلية بالتوازي مع إنشاء النافذة.
  5. التوقيع المؤجّل: Azure Trusted Signing ليس في هذا الإصدار.
- **التأثير:** `electron/main.cjs`, `assets/js/ui/router.js`, `assets/js/main.js`, `index.html`, `assets/js/lib/heic.js`, `build/installer.nsh`, `package.json` (`nsis.include`).
- **بأمر:** المستخدم (مالك المشروع) عبر AHK-31.

## 2026-08-24 — Lumen Glow v2: إنضاج Aurora الأصلي (أبيض/أسود + جلو واحد) وإعادة تصميم شاملة

- **الطلب:** «ابحث في الإصدارات السابقة لما كان مجرد صفحة واحدة ... كان فيه جلو وأبيض للفاتح وأسود للداكن وكان جلو بسيط ... استخرج نظام التصميم القديم في وثائق منفصلة ثم طوّره وانضجه ثم طبّق النظام الجديد على التطبيق بالكامل مع إعادة تصميم من الصفر لكل شاشة».
- **الاستخراج:** الكوميت `58677f4` هو الأصل (أول صفحة واحدة بـ Aurora: `aurora-blob ×3` + `glass-panel` + `blur 24–32px` + `accent-glow 0.4` + `Cairo/Inter` + `pill nav`). وُثّق حرفيًا في `docs/design-aurora-legacy.md` (توكنز، خلفية، هاب، أزرار، قوائم).
- **الإنضاج (Lumen v2):** حُفظ الجوهر «أبيض نقي/أسود نقي + جلو بسيط» وحُلّت عيوبه: قوس قزح 3 ألوان → لون واحد Indigo، `blur 32/180%` → `20/160%` للأداء، `32px + -8px scale` → `28px + -4px` للانضباط، `opacity 0.45 فاتح 0.25` → `0.16` لتباين AA. وُثّق في `docs/design-system-lumen.md` وتم اعتماده في `DESIGN.md` الجديد (Lumen tokens).
- **التطبيق الشامل:** `assets/css/app.css` أُعيد كتابته من الصفر (348 كتلة، لا ورق/صور، زجاج خفيف)، `index.html` أُضيف له `aurora` + `glass-noise` وحُدّث `DIRECTION CONTRACT`، كل الشاشات (`view-start` الهيرو + 14 أداة) تستخدم نفس شبكة `glass-panel`، أزرار `pill accent` واحدة للتنفيذ، `docrow` خطي 36×56، و`titleblock` زجاجي سفلي. الـ IDs والـ JS كما هي — تغيير بصري فقط.
- **الأثر:** واجهة أهدأ وأخف (هالتان بدل 3)، تباين أعلى في الفاتح (`slate-900` على `0.72`)، لا اعتماد على صور، `prefers-reduced-motion` محفوظ. المرجعان المنفصلان يمنعان ضياع الأصل.

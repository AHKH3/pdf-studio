# توحيد PDF Studio

التقاط أولاً، ثم الإجراءات المتاحة لهذا المزيج فقط. محلي، خفيف، بلا تكرار.

| أداة قديمة | إجراء جديد | حذف / دمج |
|---|---|---|
| بطاقة البداية «امسح مستنداً» | التقاط موحّد (صور + PDF) | تُحذف بطاقة المسح المنفردة |
| مسح مستند من صورة | **مسح** — يظهر مع الصور | يبقى محرّك المسح؛ المدخل من الحقيبة |
| صور إلى PDF | **صور → PDF** | يُدمج مسار «صور→PDF» هنا فقط (لا بطاقة ثانية) |
| PDF إلى صور | **PDF → صور** | يبقى رسماً للصفحات؛ منفصل عن الصور الأصلية |
| دمج / ترتيب / تقسيم / ضغط / علامة / ترقيم | نفس الغرض بأسماء قصيرة | تُعرض حسب العدد (دمج: PDF+، ترتيب: PDF أو مزيج) |
| sign (غير موصول) | **توقيع** | يُوصل كإجراء لـ PDF واحد |
| protect (غير موصول) | **حماية** | يُوصل كإجراء لـ PDF واحد + COOP/COEP |
| crop (غير موصول) | **قص** | يُوصل كإجراء لـ PDF واحد |
| extract-images (غير موصول) | **صور أصلية** | يُوصل — ليس «PDF → صور» |
| ocr (غير موصول) | **بحث** | يُوصل كإجراء لـ PDF واحد |
| ترتيب صفحات الكتاب | **اقتراح الترتيب** (اختياري) | أرقام الاسم → EXIF → تشابه 8×8 محلي |

مزيج الإجراءات: صور → مسح + صور→PDF. PDF+ → دمج + ترتيب. PDF واحد → بقية أدوات PDF. صور+PDF → ترتيب (+ إجراءات الصور وPDF حسب العدد).

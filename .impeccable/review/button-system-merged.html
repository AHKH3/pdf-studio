حبر مدمج — أبسط

الأساسي حبر جاف صلب (لون القلم نفسه) بحافة متعرّجة — مش نسيج جوا الزر، ومش خط تحته. الثانوي كلمة + خط قلم واحد متجعّد.

  • تنفيذ: حبر أزرق صلب + حافة قلم غير منتظمة — بدون نسيج وبدون خط تحت
  • تصفّح / أداة: كلمة + خط واحد
  • حالي: خط أحمر واحد
  • إلغاء: كلمة فقط
  • حذف: كلمة حمراء + خط أحمر واحد
